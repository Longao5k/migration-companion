# WAYmark Logo Explorations

This round intentionally removes the previous route, map, and three-node visual language. These are four scalable SVG directions for the public-facing WAYmark brand.

| Concept | Product meaning | Brand character |
| --- | --- | --- |
| `01-w-monogram.svg` | WAYmark name recognition | Bold, premium, memorable |
| `02-frame-mark.svg` | Clarity and a defined next chapter | Calm, structured, welcoming |
| `03-fold-mark.svg` | Documents, records, and verification | Practical, trustworthy, product-led |
| `04-signal-mark.svg` | Official updates and reminders | Distinctive, editorial, dependable |

Recommended starting point: `01-w-monogram.svg`. It is the least literal, works best as an App Store icon, and gives WAYmark a recognizable ownable shape beyond the migration category.
