# WAYmark Symbol Explorations v2

This round intentionally removes the previous route-and-node language and the W monogram. It also avoids literal migration symbols such as passports, flags, visas, airplanes, maps, and government seals.

| Concept | Product meaning | Character |
| --- | --- | --- |
| `01-keystone.svg` | A stable foundation for a complex process | Quiet, premium, dependable |
| `02-aperture.svg` | Clarity from a large amount of information | Editorial, precise, distinctive |
| `03-cove.svg` | A protected space for personal materials | Human, calm, companion-like |
| `04-signet.svg` | Important items are marked and confirmed | Strong, memorable, app-first |

Recommended starting point: `02-aperture.svg` if the brand should feel information-led and modern; `03-cove.svg` if the brand should feel more personal and reassuring.
