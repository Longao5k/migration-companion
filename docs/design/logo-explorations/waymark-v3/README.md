# WAYmark Function-led Logo Explorations v3

This round is based on the product's actual functions rather than the WAYmark name. It intentionally excludes letters, wordmarks, routes, map pins, milestone dots, passports, flags, and government seals.

| Concept | Function represented | Recommended use |
| --- | --- | --- |
| `01-workspace.svg` | Personal projects and material workspace | Best for a calm productivity product |
| `02-evidence.svg` | Source checking, change records, and verification | Best match for the information/evidence value |
| `03-private-core.svg` | Local-first storage and a user-controlled privacy boundary | Best match for the strongest product principle |
| `04-five-stages.svg` | Five-stage material status and process progress | Best if tracking is the lead feature |

For the current product, `02-evidence.svg` is the strongest functional direction. `03-private-core.svg` is the strongest differentiator if local-first privacy should be the primary brand promise.
