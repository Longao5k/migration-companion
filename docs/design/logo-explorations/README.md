# Migration Companion Logo Explorations

These are four non-destructive vector concepts for the current product direction. They are not wired into the mobile build yet.

| Concept | Main idea | Best brand direction |
| --- | --- | --- |
| `01-waypoint.svg` | Route + verified milestones + next step | IMMI-track / Trackwise |
| `02-gateway.svg` | A safe opening into the next stage | Waymark / Nextway |
| `03-record.svg` | Protected documents + evidence trail | Recordly / Papertrail |
| `04-compass.svg` | Orientation across a long journey | Northstar / Wayfinder |

The palette keeps the existing eucalyptus/deep-green identity, then adds restrained terracotta, sand, navy, and cobalt accents for differentiation. Before selecting a final public name, check Australian and international trademark, app-store, domain, and social-handle availability.
