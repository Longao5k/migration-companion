# 第一阶段安全与隐私工程复核

**日期：** 2026-08-28
**范围：** 南澳 SA 190/491 本地开发基线。本文是工程层威胁模型与隐私影响评估（PIA）草案，不能替代律师、隐私负责人或独立渗透测试签核。

## 1. 资产与信任边界

最敏感资产是用户上传的身份/申请材料、清单备注、提醒日期、分享 secret、访问码、身份令牌和订阅事实。官方网页快照也受访问控制，但不得与用户材料使用同一存储或权限角色。

| 流程 | 边界 | 当前控制 | 生产前仍需完成 |
| --- | --- | --- | --- |
| 访客项目 | App 私有目录/加密本机仓库 | 不注册可用；注册不自动上传；备份加密并逐文件校验 SHA-256 | iOS/Android 真机卸载、锁屏、备份与恢复矩阵 |
| 账号同步 | App → API → PostgreSQL | 对象级授权；本机先保存；幂等操作；409 由用户选择，不在冲突摘要显示备注正文 | Cognito、短时 token、刷新/吊销、多设备与异常登录告警 |
| 文件上传 | App → 预签名 S3 隔离区 → 完成校验 → 扫描 | API 不承载主路径文件字节；类型/大小/hash/魔数校验；待扫描不可下载；过期会话清对象 | 独立恶意软件扫描 worker、隔离桶策略、KMS、告警和失败重放 |
| 安全分享 | 接收者 → 公共分享 API → 短时下载 | secret 放 URL fragment；访问码散列；错误锁定；默认 7 天、禁止下载、可撤销 | WAF/分布式限速、滥用检测、生产邮件与真实外部网络测试 |
| 政策内容 | 白名单爬虫 → 证据存储/审核 → 公开 API | SSRF（服务端请求伪造）阻断；草稿不公开；重要变化人审；更正留痕 | 生产证据桶、不可变保留、来源许可逐页复核、审核 SLA |
| 通知 | 已核实变更事务 → Outbox → 推送 worker | 数据与任务同事务；去重；有限重试；锁屏文案不含摘要、来源和用户资料 | APNs/FCM token 模型、凭据、退订/失效 token 清理与两端沙盒 |
| 账号删除 | 7 天撤回 → 删除 worker → 最小 ledger | 删除对象后才删记录；失败可重试；ledger 只留 HMAC hash、时间、数量和状态 | 定时任务互斥、备份/日志销毁证明、35 天目标验证、隐私负责人签核 |

系统不得宣传端到端加密：服务端需要在受控任务中解密文件以完成扫描、分享、转换和协作。准确表述是传输加密、设备保护、云端 KMS 加密、最小权限和可审计处理。

## 2. 主要威胁与现有处置

| 威胁 | 处置与验收证据 | 残余风险 |
| --- | --- | --- |
| 越权读取/修改别人的项目或文件 | 服务端逐动作 owner/collaborator/viewer 检查；下载和删除权限有端到端测试 | 生产身份尚未接入，需渗透测试验证 IDOR（不安全直接对象引用） |
| 重试导致重复写入或覆盖 | 稳定 operation ID、payload hash、数据库事务；重复完成上传返回同一文件 | 多区域/多 worker 并发尚未压测 |
| 上传伪装、超额或孤立对象 | 允许类型、大小、SHA-256、魔数、已用+预留额度；10 分钟会话；过期清理作业 | 真实恶意样本、压缩炸弹与扫描隔离尚未验证 |
| secret/敏感正文进入日志或通知 | 审计只写安全元数据；冲突不含备注正文；推送 payload 使用通用标题 | 生产可观测平台与第三方 SDK 遥测需单独审查 |
| 删除只删数据库、不删对象 | 文件与账号删除均先幂等删除对象，再删记录；对象失败时保留可重试记录 | 备份、日志、CDN 缓存和供应商副本需要生产演练 |
| 抓取器被用于内网探测 | 仅官方白名单、解析 DNS 后拒绝私网/保留地址、限制重定向与响应 | DNS rebinding、代理和云元数据端点需生产网络层再限制 |
| 客户端伪造订阅权益 | 权益由服务端保存，客户端不能直接授予 | Apple/Google 服务端签名验证和通知尚需真实账号 |
| 第三方文档 SDK 数据/许可风险 | 文档引擎适配层隔离；当前仅用于内部评估 | 正式发布必须完成自研替换或取得明确商业分发授权 |

## 3. 数据最小化与删除

- 默认本机优先；账号、云文件、协作和远程通知必须由用户明确开启。
- 审计、删除 ledger、worker 错误与通知任务不得保存文件正文、原文件名、证件号、访问码或分享 secret。
- 账号删除申请保留 7 天撤回窗口；到期作业最多每批 25 个账号，任何对象删除失败都不宣告完成。
- 未完成上传会话 10 分钟到期；清理 worker 每批最多 100 个，先幂等删隔离对象，再删会话。
- 本地实现无法证明云备份副本已在 35 天内清除；这仍是生产发布硬门，禁止使用“立即永久删除所有副本”的文案。

## 4. 发布结论

第一阶段**本地可实现的安全与隐私控制通过工程复核**。这不是上线许可。生产发布必须完成：身份与商店服务端核验、APNs/FCM、独立扫描、云端最小权限与备份删除演练、依赖/SBOM（软件物料清单）和独立渗透测试，并由澳洲合资格专业人士签核移民协助边界、Privacy Act/APP/NDB、抓取版权、隐私政策、条款、订阅和商店披露。
