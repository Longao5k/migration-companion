# 第一阶段商业授权与发布门槛

**状态：路线已决定。开发阶段使用免费评估组件，正式发布前由自研 SDK 替换；如替换未通过，再单独决定是否购买商业许可。未通过前不得宣称可上架。**

## 1. 文档编辑组件

第一阶段冻结的文档能力需要：

- Apryse Flutter/Native SDK：iOS/Android PDF 查看、批注、表单、页面操作与保存副本；
- ONLYOFFICE Docs Developer：登录用户在移动 WebView 中编辑受支持的简单 DOCX；
- 两项组件均须确认商业报价、移动端分发权、生产授权方式、数据处理条款、遥测行为和技术支持范围；
- 取得官方评估许可后，必须用 iOS/Android 真机和代表性文档语料完成能力矩阵验证；失败时保留原件并明确降级，禁止静默损坏。

社区版 ONLYOFFICE 不满足当前冻结的移动集成与商业发布方案，因此不能用社区版假装完成 P0。没有有效评估或商业许可时，代码只允许保留兼容性预检和明确的“尚未启用”状态。

## 2. 云账号与身份

生产联调需要由产品所有者提供或授权创建澳洲区域的 AWS 资源，包括 Cognito、PostgreSQL、S3/KMS、邮件投递、WAF、日志和备份。任何真实用户材料进入云端前，须先完成数据流、权限、删除、备份恢复和事件响应审查。

## 3. 应用商店与订阅

需要 Apple Developer 与 Google Play Console 账号、应用标识、税务/收款资料以及月付/年付订阅商品。只有两端沙盒完成购买、恢复、续订、退款、撤销、过期和换机验证后，服务端权益系统才可签核。

## 4. 法律与公开信息

发布前需要确定运营主体法定名称、联系邮箱、支持地址、隐私负责人和数据保留期限，并由澳洲合资格专业人士复核：

- 产品不构成移民协助或个案法律建议的边界；
- Privacy Act / Australian Privacy Principles、跨境披露和数据泄露响应；
- 南澳及联邦官方页面的抓取、证据留存、引用和版权用法；
- 隐私政策、使用条款、订阅说明、退款说明和商店隐私披露。

## 5. 产品所有者决定

保持已冻结的完整第一阶段范围。当前项目用 Apryse 免费评估能力和 ONLYOFFICE Developer 试用环境继续开发，并通过自有适配器隔离。自研 PDF/DOCX SDK 在独立工作流中并行实现；公开发布前完成替换。若自研版本届时未通过验收，再由产品所有者决定是否购买短期生产许可，不提前付款。
