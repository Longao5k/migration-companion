# 第一阶段商业授权与发布门槛

**状态：PDF 已接入自研 SDK；第三方 PDF 商业许可不再是当前发布依赖。自研 Alpha 的双平台语料与商店构建验收仍未通过，未通过前不得宣称可上架。**

## 1. 文档编辑组件

PDF 第一阶段现状：

- 使用产品所有者自研 `document_sdk` `v0.1.0-alpha.4`，不含第三方 PDF 引擎商业分发许可依赖；
- 支持逐文件 capability、查看、搜索/选择、批注、手写、表单、页面操作、撤销/重做与验证后另存副本；
- 必须用 iOS/Android 真机和代表性文档语料完成能力矩阵验证；失败时保留原件并明确降级，禁止静默损坏；
- 未内嵌字体的页面必须报告 gap；替代字体结果可以 `complete` 但不一定 `exact`，界面与测试不得混淆；
- DOCX 当前仍交给系统应用查看；若以后恢复内置编辑，必须另行完成引擎、许可/自研与移动端验收。

不得重新引入 Apryse、ONLYOFFICE 或其他评估组件到公开测试/商店构建，除非先取得明确的生产与终端分发权并重新完成数据流审查。

## 2. 云账号与身份

生产联调需要由产品所有者提供或授权创建澳洲区域的 AWS 资源，包括 Cognito、PostgreSQL、S3/KMS、邮件投递、WAF、日志和备份。任何真实用户材料进入云端前，须先完成数据流、权限、删除、备份恢复和事件响应审查。

## 3. 应用商店与订阅

需要 Apple Developer 与 Google Play Console 账号、应用标识、税务/收款资料以及月付/年付订阅商品。只有两端沙盒完成购买、恢复、续订、退款、撤销、过期和换机验证后，服务端权益系统才可签核。

## 4. 法律与公开信息

发布前需要确定运营主体法定名称、联系邮箱、支持地址、隐私负责人和数据保留期限，并由澳洲合资格专业人士复核：

- 产品不构成移民协助或个案法律建议的边界；
- Privacy Act / Australian Privacy Principles、跨境披露和数据泄露响应；
- 澳洲各州、领地及联邦官方页面的抓取、证据留存、引用和版权用法；
- 隐私政策、使用条款、订阅说明、退款说明和商店隐私披露。

## 5. 产品所有者决定

资讯第一阶段覆盖全澳洲与全部移民类型，南澳作为首发市场和材料模板起点。PDF 使用自研 SDK；不为已替换的 PDF 引擎预付第三方许可。若未来加入 DOCX 内置编辑或自研 SDK 未通过发布验收，再由产品所有者单独决定替代方案。
