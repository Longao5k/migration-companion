# 第一阶段数据边界

| 数据 | 默认位置 | 可访问主体 | 关键规则 |
| --- | --- | --- | --- |
| 访客项目与文件 | 用户设备私有空间 | 当前设备用户 | 不因注册自动上传；卸载前需主动备份 |
| 账号与项目元数据 | AWS Sydney 数据单元 | 本人及对象级授权协作者 | Cognito 身份；服务端逐动作授权 |
| 用户云文件 | 私有 S3 + 独立 KMS | 本人、授权协作者、短时文档处理任务 | 不公开；不把对象 key 当授权；新版本不可变 |
| 外部分享 | API 授权 + 短时下载 | 持有链接 secret 与访问码的接收方 | 默认 7 天、禁止下载、可撤销；已保存副本不可追回 |
| 官方页面证据 | 独立私有证据存储 | 采集与内容审核角色 | 只抓白名单；不作为自有全文发布 |
| 新闻与 Change Log | 内容数据库 | 公开读取、内容人员审核 | 重大/重要变化人审后发布；更正留痕 |
| 订阅 | 商店事实 + 服务端权益 | 本人、计费服务、受限支持人员 | 客户端不能自行授予权益 |
| 审计日志 | 独立审计域 | 受限安全/支持角色 | 不含正文、原文件名、证件号、访问码或 URL secret |

系统不宣传端到端加密。服务器需要在受控任务中解密文件以完成病毒扫描、分享、转换和协作编辑；准确表述是设备保护、传输加密、云端 KMS 加密、最小权限和可审计处理。
